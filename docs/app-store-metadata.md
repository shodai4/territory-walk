## 5. Appのプライバシー (App Privacy 回答ガイド)

App Store Connectの「Appのプライバシー」設定で、以下の通り回答してください：

1. 「このAppからデータを収集しますか？」 ＞ **「はい」**
2. 収集するデータタイプ：
   - **位置情報 (Location)** ＞ **おおよその位置情報 (Coarse Location)** および **正確な位置情報 (Precise Location)**
   - **識別子 (Identifiers)** ＞ **デバイスID (Device ID)**（広告識別子 IDFA。AdMob が広告配信に使う）
   - **使用状況データ (Usage Data)** ＞ **広告データ (Advertising Data)** と **製品のインタラクション (Product Interaction)**（AdMob の広告表示／クリック、ゲーム内操作）
3. 各データの使用目的：
   - 位置情報 ＞ **Appの機能 (App Functionality)**
   - デバイスID・広告データ ＞ **第三者広告 (Third-Party Advertising)**
   - 製品のインタラクション ＞ **Appの機能 (App Functionality)**（週間ランキングの集計）
4. 「このデータはユーザーの身元に関連付けられていますか？」 ＞ **「いいえ」**（アカウント登録不要・端末内で生成した匿名UUIDのみ）
5. 「このデータをトラッキング目的に使用しますか？」 ＞ **「はい」**（デバイスID／広告データのみ。「App Tracking Transparency で許可を得た場合に限る」）
   - ⚠ ATT の許可要求を実装している以上、ここを「いいえ」にすると申告と実装が食い違い、審査で指摘されます。
   - 位置情報そのものをトラッキング目的には使いません（陣地判定＝Appの機能のみ）。

## 8. ビルド・動作環境・広告まわりの前提

- **最低対応OS**: iOS 15.0（`scripts/configure-ios.js` が Podfile と `IPHONEOS_DEPLOYMENT_TARGET` を 15.0 に揃える）
  - Capacitor のテンプレートは 13.0 だが、TestFlight アップロード時に警告 **code 90068**
    （「2027年4月以降は iOS 15.0 以上が必須」）が出ていたため 15.0 に引き上げ済み。
- **App Store Connect の「デベロッパWebサイト」**: 任意項目。設定する場合は `https://shodai4.github.io/territory-walk/`
  を入れ、`app-ads.txt` を**そのドメインのルート**（`https://shodai4.github.io/app-ads.txt`）に置く。
  - リポジトリ直下の `app-ads.txt` は `google.com, pub-5739782559889389, DIRECT, f08c47fec0942fa0`。
    GitHub Pages のプロジェクトサイトでは `/territory-walk/app-ads.txt` にしかならないため、
    ルートに置くには `shodai4.github.io` リポジトリの作成（または `shodai4.com` 取得後のカスタムドメイン）が必要。
  - 未設置でも審査は通るが、Google 側の販売者確認が完了せず広告収益が制限されることがある。
- **SKAdNetworkItems**: `cstr6suwn9.skadnetwork`（Google）を Info.plist に設定済み。
  AdMob 管理画面の「SKAdNetwork」一覧を追加すると更に充填率が上がる（任意）。
- **ATT**: `NSUserTrackingUsageDescription` に目的と「拒否しても全機能が使える」旨を記載済み（`scripts/configure-ios.js`）。
