# v1.1 プライバシー設計＋Apple Watch（実装メモ）

対象ブランチ: `feat/v1.1-privacy-watch`（`main` には触れない）
前提: v1.0（`main`）は App Store 審査中。v1.0 の審査通過後にマージして TestFlight 配信する。

---

## 1. 初期配置ランダム50%（白/黒）

- `grid.js` の `deterministicInitialTeam(weekId, latIdx, lngIdx)` が
  `week_id + 座標` の FNV-1a ハッシュから `white` / `black` を決める（ビット1本＝50:50）。
- 同じ週・同じ座標なら誰の端末でも同じ色。週（`week_id`）が変われば自動でシャッフルされる。
- **DBは1行も増えない**（未登録マスは保存しない）。
- 塗りは `TILE_FILL_OPACITY = 0.45` に統一。初期配置と実際の陣地を**同じ濃さ**にして、
  見た目で「人が歩いた場所」が判別できないようにした（下の地図は透けて読める）。

## 2. 自分の足跡（端末内のみの枠線）

- `grid.js` の `recordFootprint(meshId)` が自分が塗ったマスを `localStorage: tw_footprint`
  に週単位で記録（最大3,000マス、週替わりで自動消去）。
- 描画時は `getTileStyle(team, { ownFootprint: true })` で枠線だけをアンバー・太めにする。
- **サーバーへは送らない**（Supabase の書き込みは `territory_tiles` のみで、足跡は含めない）。
  他人の画面には一切出ない。

## 3. 非表示ピン（プライバシーゾーン）

- `privacy.js`。最大5件・半径300m/500m・名前ラベル（自宅/職場/学校/実家プリセット）。
- 登録時に中心を **半径の20〜30%** ランダムにずらし、ずらした後の座標だけを
  `localStorage: tw_privacy_zones` に保存する（真の中心は残さない）。
- 保存項目は `id / label / lat / lng / radius / createdAt` のみ。Supabase へは送らない。
- 区域の中は `processMeshAndClaim` の入口で止める：
  塗らない・Outboxに積まない・スコア/コイン/戦績に数えない（A案）。
- 描画も `resolveTileTeam` が区域の中を「初期配置」に戻すので、
  過去に塗ってしまったマスが残っていても区域の位置は分からない。
- UI: メニュー「非表示ピン（自宅・職場）」→ モーダル。
  「現在地で登録」／「地図タップで登録」／一覧から削除。地図には破線の円で表示（自分だけ）。

## 4. 月曜リセット後の結果発表・無音通知

- `notifications.js` ＋ `@capacitor/local-notifications`（6系）。
- 予約は「次の月曜09:00（端末ローカル時刻）」の1件だけ。起動のたびに同じIDで貼り直す
  （通知センターに溜めない）。
- **無音**: `sound` を指定しない（iOSは「音を出さない通知」として通知センターに入れる）。
  アプリを開いている間に重ねて出さないよう `silent: true`。
- **権限**: 既定OFF。ユーザーが「月曜の結果通知（無音）」をONにした瞬間だけ
  `requestPermissions()` を呼ぶ。起動時は `checkPermissions()` のみで、許可ダイアログを出さない
  （位置情報・ATTのダイアログと干渉しない）。

## 5. Apple Watch（コンパニオン Phase 1）

- 3要素だけ: ①地図＋陣地マス ②＋／－ ③マーキングON/OFF。
  （v1.2 で ②＋／－ を廃止し、ズームは Digital Crown の4段階へ移した）
- iPhone 側 `WatchBridgePlugin.swift`（WatchConnectivity）が状態を
  `updateApplicationContext` で送り、Watch の操作を `sendMessage` で受ける。
- Watch のマス色は iPhone と同じ `resolveTileTeam` を通す（初期配置・実績・非表示ピンすべて一貫）。
- 無音通知（陣地取得・奪還）は `silent.wav` を通知音にして、Watch の手首振動を残す方式。
- CI への組み込みは `vars.ENABLE_WATCH_TARGET == 'true'` のときだけ。
  ステップ定義は `ci/watch-step.yml`、挿入は `node scripts/apply-watch-workflow-step.js`
  （Pickle の GitHub App は `.github/workflows/` を push できないため、本人の push で反映する）。
  詳細と有効化手順は `watch/README.md`。

## リリース手順（v1.0 審査通過後）

1. `feat/v1.1-privacy-watch` のテストが全PASS を確認（`npm test`）。
2. Watch を同時に出す場合だけ、`node scripts/apply-watch-workflow-step.js` で
   ワークフローにステップを挿入して commit/push（未挿入でも iOS 単体は今までどおり動く）。
3. `main` にマージ（v1.0 が配信済み／審査通過済みであること）。
4. main push で CI がアーカイブ＆TestFlight 配信（Watch は変数ONのときだけ含む）。
5. TestFlight で実機確認（`watch/README.md` の「実機確認」）。
6. App Store Connect で v1.1 の「このバージョンの新機能」に以下を記載：
   - 周りのマスが白/黒で埋まり、歩いた場所が分かりにくくなりました
   - 自宅・職場を「非表示ピン」で隠せます（最大5か所・端末内のみ）
   - 月曜9時に先週の結果を無音でお知らせします（設定でON/OFF）
7. プライバシーポリシーに「非表示ピンの座標は端末内にのみ保存」を追記。

## 未検証・要確認（実機／CIで1回ずつ）

- Watch ターゲットの初回ビルド（`vars.ENABLE_WATCH_TARGET=true` で1回 dispatch して確認）。
  落下地点の候補は `watch/README.md` の表。
- `packageClassList` による `WatchBridgePlugin` の自動登録が効くか（効かない場合は
  Watch 側の画面が「iPhoneと接続中」のままになる。クラッシュはしない）。
- 月曜9時の通知が実機で無音かつ通知センターに残るか（`silent` の挙動）。
- Watch アイコンは既存アイコンを明るい背景に置いた暫定版。デザイン差し替えは
  `resources/icon-source.png` を替えて `scripts/generate-watch-assets.py` を再実行するだけ。
